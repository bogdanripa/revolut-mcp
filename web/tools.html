Revolut MCP Setup Tools GitHub

Tools

Everything the server exposes, grouped the way it is grouped in the code. Read tools work with the minimum Revolut permission; write tools need the matching permission granted on the consent screen, and fail with HTTP 403 if it was not.

Tools marked writes money move real funds and cannot be undone. Your assistant is instructed to confirm the counterparty, amount and currency with you first, but the real control is the permission set you grant Revolut — if you never tick the payment permissions, these tools cannot do anything.

Pairing it with invoicing

The reason this exists: add an invoicing MCP server alongside it and the two answer questions neither can alone — which issued invoices have actually landed in the bank, what is still outstanding, which incoming transfer matches which document. Ask for a date range, let it pull the statement, and match on counterparty and amount.
